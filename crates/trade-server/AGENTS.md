# Agent Guidelines

Guidelines for AI coding agents working on this codebase.

## Before Making Changes

1. Read `docs/architecture.md` to understand the system design and component relationships.
2. Review the relevant module documentation in `docs/design/` for detailed specifications.

## After Making Changes

Update `docs/architecture.md` if your changes affect:
- Directory structure
- Component responsibilities
- Data flow or event routing
- Integration points or external dependencies
